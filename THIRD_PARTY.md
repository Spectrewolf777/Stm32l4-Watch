## Not included: ST Edge AI

ST Edge AI Core's runtime library and generated network code (`Middlewares/ST/AI/`,
`Core/AI/network*`) are under ST's proprietary SLA0044 licence, so they are not in this repo and
are not covered by the licences above. Run `tools/update_model.sh` to create them locally. See
`docs/SOUND_ALERTS.md`.

## Training data

The trained model in `training/out_open/` uses only:

* FSD50K clips licensed CC0 or CC-BY. FSD50K: E. Fonseca, X. Favory, J. Pons, F. Font, X. Serra,
  "FSD50K: An Open Dataset of Human-Labeled Sound Events", IEEE/ACM TASLP, 2022. Every clip used
  is credited in `training/ATTRIBUTION_FSD50K.csv` (title, uploader, Freesound link, licence).
* Synthetic alarm and siren sounds generated by `training/synth_alarms.py`.
